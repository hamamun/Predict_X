PREDICT-X User Guide

Latest build guide — prediction, scoring, optional auto-trading, online AI, candlestick confirmation, and smart trade management.

1. What PREDICT-X Does

PREDICT-X is a MetaTrader 5 Expert Advisor that analyzes closed candles, scores market conditions, predicts BUY/SELL/NO TRADE, and optionally places/manages trades.

Native MT5/MQL5 only. No martingale. No grid. Closed-bar signals only.

4. Main Scoring

The EA uses these layers:

  • Smart Money / SMC
  • Trend and Momentum
  • VWAP / Keltner / Session / Spread
  • Higher Timeframe Confluence
  • Markov Chain
  • Online AI Confirmation
  • Candlestick Confirmation bonus

Final score is capped at 100.

5. Candlestick Confirmation

Candlestick confirmation is a small support layer only:

  • BUY support: bullish engulfing, hammer/pin, morning star, strong bullish close.
  • SELL support: bearish engulfing, shooting star/pin, evening star, strong bearish close.
  • Near VWAP/Order Block can add a small bonus.
  • Maximum bonus: +5.
  • It never subtracts points and never creates trades alone.
  • Opposite candle warning can block market entry.

6. Entry Logic

  • Very Strong = market.
  • Strong + momentum/not extended = market.
  • Strong extended = market only if ADX very strong and spread low; otherwise limit.
  • Medium near 69 + strong momentum = market.
  • Normal Medium = VWAP / Order Block limit.

Pending setup refreshes every closed bar. Stale/invalid orders are updated or cancelled.

7. Broker-Aware TP/SL

The EA now adjusts TP/SL to satisfy broker stop/freeze distance rules.

  • BUY TP must be above valid broker distance.
  • BUY SL must be below valid broker distance if initial SL is used.
  • SELL TP must be below valid broker distance.
  • SELL SL must be above valid broker distance if initial SL is used.
  • If adjustment makes R:R too poor, the setup is rejected.

8. Trade Management

Before TP1

  • 1/3 to TP1: SL to breakeven/spread buffer.
  • 2/3 to TP1: SL locks 1/3 profit.
  • 90% to TP1: SL locks 2/3 profit.
  • EA tracks best favorable price before TP1 so fast moves are not missed.

At TP1

  • Closes 50% if broker volume allows.
  • Attempts breakeven, but SL never moves backward.

After TP1

  • If price reaches halfway from TP1 to TP2, SL locks to TP1.
  • Then 30% giveback trail protects remaining profit.
  • SuperTrend/ATR/profit-lock trailing also manages the runner.

9. Active Prediction Monitor

After entry, the EA keeps checking the prediction every closed bar.

  • Moderate weakness = tighten only.
  • No trade / heavy weakness / opposite signal = close only if profit is above broker-cost buffer.
  • Never closes a negative trade only because prediction changed.

10. Online AI

  • Less than 20 evaluated signals = learning mode, +0.
  • After 20 samples, AI may add +5 or +10 if it agrees.
  • AI never subtracts and never trades alone.
  • AI is chart-symbol based and persisted with MT5 Global Variables.

11. Panels

Main Panel

Regime, total score, signal, scoring layers, market context, signal state.

Setup / Order Manager

Shows when setup/order/trade exists. Displays entry, SL, TP1, TP2, breakeven, lot, risk/reward, current P/L, early lock, post-TP1, trailing, and last action.

12. Safety Notes

  • If Use Initial Stop Loss = false, there is no broker-side SL before protection logic moves SL.
  • Test on demo first.
  • Manual orders are not managed unless they use PREDICT-X magic number.
  • If trade opened on one timeframe, another timeframe cannot signal-close it.
